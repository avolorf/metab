# Проверка бланков на алкилдиэтаноламины по сырым файлам (.raw)

Цель — выяснить, откуда в моче ряд алкилдиэтаноламинов (индекс загрязнения): из прибора/растворителей, из расходников
пробоподготовки (пробирки, наконечники, фильтры) или из контейнеров для мочи. Для этого нужны XIC целевых ионов
в бланках, QC и нескольких пробах. Обработка — скриптом `blank_check.py` (MS-DIAL не нужен: при выравнивании в MS-DIAL
фильтр по бланкам удаляет как раз то, что мы хотим увидеть).

## 1. Какие файлы взять (из каждого батча)
| тип (`type`) | что это | сколько |
|---|---|---|
| `solvent_blank` | инъекция чистого растворителя (метанол–вода 50:50) | все, что есть |
| `process_blank` | вода/растворитель, прошедшие всю пробоподготовку в тех же пробирках, с теми же наконечниками | все, что есть |
| `container_blank` | вода, постоявшая в пустом контейнере для сбора мочи, затем обычная пробоподготовка | если есть (очень желательно; если нет — можно сделать сейчас и вколоть) |
| `QC` | пулированный QC | все (в s266 их 6) |
| `sample` | пробы с самым высоким индексом (s266: **11, 67, 39** — РПЖ) и самым низким (**7, 86** — контроли) | 4–6 |

Важно: бланки, вколотые **сразу после** пробы или QC, дополнительно покажут перенос (carryover) — для этого нужен
порядок инъекций.

## 2. Установить ProteoWizard (Windows)
1. https://proteowizard.sourceforge.io/download.html → «Windows 64-bit» (версия с vendor-библиотеками; Thermo .raw
   читается только под Windows).
2. После установки в меню «Пуск» появится **MSConvertGUI**.

## 3. Конвертация .raw → mzML (урезанные файлы)
Нужны только MS1-спектры, m/z 250–450 и RT 9–19 мин — там лежат все ионы ряда и два контрольных эндогенных иона.
Так каждый файл займёт единицы–десятки МБ вместо сотен.

**MSConvertGUI:**
1. *Browse* → выбрать .raw файлы из п. 1 → *Add*.
2. *Output Directory*: новая папка, например `D:\blankcheck_mzml`.
3. *Options*: Output format **mzML**; Binary encoding precision **32-bit**; ✔ **Write index**; ✔ **Use zlib compression**;
   ✘ TPP compatibility; ✘ Package in gzip.
4. *Filters* — добавить **в этом порядке** (выбрать фильтр в списке → задать параметры → *Add*):
   1. **Peak Picking**: Algorithm *Vendor*, MS Levels *1-* (обязательно первым);
   2. **MS Level**: *1-1*;
   3. **Scan Time**: Start *540*, End *1140* (секунды = 9–19 мин);
   4. **m/z Window**: *250* – *450*.
5. *Start*.

**То же из командной строки** (в папке с .raw):
```
msconvert *.raw --mzML --32 --zlib -o D:\blankcheck_mzml ^
  --filter "peakPicking vendor msLevel=1-" ^
  --filter "msLevel 1" ^
  --filter "scanTime [540,1140]" ^
  --filter "mzWindow [250,450]"
```
Проверка: откройте один mzML в SeeMS (входит в ProteoWizard) — должны быть только MS1-спектры от ~9 до ~19 мин.

## 4. Список инъекций `injections.csv`
Одна строка — один файл. Шаблон: `metadata/injections_blankcheck_template.csv`.

| столбец | содержание |
|---|---|
| `file` | имя mzML-файла, точно как на диске |
| `type` | `solvent_blank` / `process_blank` / `container_blank` / `QC` / `sample` |
| `batch` | батч (например, `s266`) |
| `order` | номер инъекции в последовательности этого батча (для оценки переноса) |
| `sample` | номер пробы как в metadata (для `sample`), иначе пусто |

В список **не включайте** ФИО и другие персональные данные — только номера.

## 5. Передать файлы
Заархивируйте папку с mzML и `injections.csv` (zip) и загрузите в чат. Если архив слишком большой, разбейте по
батчам. Положить их нужно в `data/raw_check/` (эта папка не попадает в git).

## 6. Что сделает скрипт
```
pip install -r requirements.txt
python blank_check.py              # читает data/raw_check/*.mzML и data/raw_check/injections.csv
```
Для каждого члена ряда (m/z по формуле, ±5 ppm) и двух эндогенных контрольных ионов: апекс в окне ±0.5 мин от
ожидаемого RT (с поправкой на медианный сдвиг RT по QC), площадь пика. Результаты в `results/blank_check/`:
* `blank_check_areas.csv` — площади во всех инъекциях;
* `blank_check_summary.csv` — медианы по типам, доля от медианы QC и вывод;
* `blank_check_carryover.csv` — бланк сразу после пробы/QC: % от предыдущей инъекции;
* `blank_check.png/.pdf` — площади по типам инъекций и XIC C12-DEA (m/z 274.2741).

Правило вывода (задано заранее): соединение присутствует в бланке, если площадь ≥ 10 % медианы QC;
* есть в solvent-бланке → фон прибора/растворителей или перенос;
* только в process/container-бланке → расходники (пробирки, контейнеры);
* нет в бланках → источник до лаборатории (контейнер у пациента, хранение) или эндогенное — тогда нужен container-бланк.
Эндогенные контрольные ионы (стероид C19H28O3, тетрагидрокортизон) в настоящем бланке должны отсутствовать —
это проверка, что бланк не загрязнён пробой.

## 7. Если хотите проверить все признаки, а не только ряд
Конвертируйте без фильтров Scan Time и m/z Window (файлы будут крупнее) или повторите выравнивание в MS-DIAL
с **выключенным** фильтром по бланкам и экспортируйте таблицу, где бланки — отдельные столбцы с именами `Blank…`;
`run_all.py` тогда сам применит фильтр QC/бланк ≥ 5 и покажет, какие признаки он удаляет.
