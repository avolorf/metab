# 1. Назначение

СОП описывает последовательность действий от исходных файлов масс-спектрометра (.raw) до:

- таблицы площадей пиков в формате, который принимает разработанный фреймворк;
- результатов статистической обработки.

Цель — сделать результаты разных серий и выборок воспроизводимыми и сопоставимыми.

# 2. Термины и сокращения

- **Признак** — пара «m/z – время удерживания (RT)», выявленная при разметке и выравнивании.
- **Соединение** — группа признаков одного вещества: аддукты, изотопы, фрагменты источника.
- **QC** — пулированный образец контроля качества (смесь равных аликвот всех образцов серии).
- **Бланк** — инъекция чистого растворителя (метанол), прошедшего ту же пробоподготовку.
- **Серия (батч)** — непрерывная последовательность инъекций с собственными QC и бланками.
- **RSD** — относительное стандартное отклонение.
- **PQN** — вероятностная коэффициентная нормализация.
- **MSI** — уровни достоверности аннотации по Metabolomics Standards Initiative.

# 3. Программное обеспечение

| ПО | Версия | Назначение |
|---|---|---|
| ProteoWizard msconvert | 3.0 и выше | конвертация .raw → .mzML (если MS-DIAL не читает .raw напрямую) |
| MS-DIAL | 5.5 | разметка, деконволюция, аннотация, выравнивание |
| Библиотека NIST HR-MS/MS | в формате .msp | аннотация по спектрам MS/MS |
| Python | 3.13 + пакеты из `requirements.txt` | фреймворк обработки (`run_all.py`) |

# 4. Требования к исходным данным

## 4.1. Именование файлов

- Латиница, без пробелов и кириллицы.
- Номер образца — тот же, что в журнале образцов.
- Образцы: `S001`, `S002`, …
- QC: `QC01`, `QC02`, … — сквозная нумерация по всем сериям.
- Бланки: `Blank01`, `Blank02`, … — сквозная нумерация. Дополнительные бланки в начале серии: `Blank00`, `Blank000` или с номером серии (`B2_Blank00`). Повторов номеров быть не должно.

## 4.2. Журнал последовательности инъекций

Заполняется до начала измерений и хранится вместе с данными. Это единственный источник сведений о порядке инъекций и сериях.

| Столбец | Пример | Примечание |
|---|---|---|
| file | QC02 | имя файла без расширения |
| type | QC | Sample / QC / Blank |
| class | QC | BC / Control / PC / QC / Blank |
| batch | 1 | номер серии |
| injection_order | 9 | сквозной порядковый номер инъекции, включая бланки |
| sample | — | номер образца для типа Sample |

Рекомендуемая схема серии:

> Blank00 → Blank000 → Blank → QC → 6 образцов → Blank → QC → … → последний блок образцов → Blank → QC

Порядок образцов внутри серии рандомизируется так, чтобы группы были представлены в каждой серии в сопоставимых долях.

## 4.3. Метаданные образцов

Файл `metadata/metadata_<выборка>.csv` со столбцами:

| Столбец | Содержание |
|---|---|
| sample | номер образца |
| group | группа |
| sex | M / F |
| age | возраст |
| include | 1 / 0 |
| exclude_reason | причина исключения |
| injection_order | порядок инъекции |
| comment | диагноз |

Образцы с диагнозами вне дизайна исследования (другие локализации рака, неопухолевые заболевания) помечаются `include = 0` с указанием причины. Из таблицы данных их не удаляют.

# 5. Порядок выполнения

## 5.1. Конвертация (если требуется)

Если MS-DIAL (Windows, с установленным Thermo RawFileReader) открывает .raw напрямую, шаг пропускается. В противном случае:

```
msconvert *.raw --mzML --32 --zlib --filter "peakPicking vendor msLevel=1-" -o mzML/
```

Проверка: число файлов .mzML равно числу .raw; размер файлов сопоставим; один файл QC открывается в MS-DIAL или SeeMS с ожидаемым видом хроматограммы.

## 5.2. Создание проекта MS-DIAL

1. File → New project. Задать:
   - Ionization type — Soft ionization;
   - Separation type — Chromatography (LC);
   - MS method type — Conventional LC/MS или DDA;
   - Data type MS1 — Centroid, MS2 — Centroid;
   - Ion mode — Positive;
   - Target omics — Metabolomics.
2. Импортировать все файлы серии (серий): образцы, QC и бланки.
3. В таблице файлов заполнить для каждого файла по журналу последовательности (п. 4.2):
   - **Type** — Sample / QC / Blank;
   - **Class ID**;
   - **Batch**;
   - **Analytical order**;
   - **Included**.

## 5.3. Параметры обработки

Таблица 1 — Параметры MS-DIAL

| Раздел | Параметр | Значение |
|---|---|---|
| Data collection | MS1 tolerance | 0.01 Да |
| | MS2 tolerance | 0.025 Да |
| | Диапазон RT / m/z | весь градиент / 150–1500 |
| Peak detection | Minimum peak height | 100 000 |
| | Mass slice width | 0.1 Да |
| | Smoothing | линейно-взвешенное скользящее среднее, 15 сканов |
| | Minimum peak width | 10 сканов |
| MS2Dec | Sigma window | 0.5 |
| | MS2 abundance cut-off | 0 |
| | Exclude after precursor | да |
| | Keep isotope ions until | 5 Да |
| Identification | Библиотека | NIST HR-MS/MS (.msp) |
| | Использование RT | нет |
| | Accurate mass tolerance MS1 / MS2 | 0.01 / 0.025 Да |
| | Simple / weighted dot-product cut-off | 600 / 600 у.е. |
| | Matched spectrum percentage | 25 % |
| | Minimum matched peaks | 3 |
| Adducts | Положительный режим | [M+H]⁺, [M+NH₄]⁺, [M+Na]⁺, [M+K]⁺, [M+H−H₂O]⁺, [2M+H]⁺, [2M+Na]⁺ |
| Alignment | Reference file | QC из середины серии |
| | RT tolerance | 0.1 мин |
| | MS1 tolerance | 0.015 Да |
| | RT factor / m/z factor | 0.5 / 0.5 |
| Фильтрация | Remove features based on blank information | да; максимум в образцах ≥ 5 × среднее в бланках |
| | Keep reference matched features | нет |
| | Gap filling by compulsion | **нет** |
| Normalization | Метод | **none** |

Пояснения к параметрам:

- **Аддукты [M+NH₄]⁺ и [M+H−H₂O]⁺** добавлены к перечню прежнего проекта. Глюкурониды и другие конъюгаты в используемых условиях регистрируются преимущественно в этих формах.
- **Референсный файл для выравнивания — QC.** QC содержит практически все соединения выборки, поэтому выравнивание по нему устойчивее, чем по отдельному образцу.
- **Заполнение пропусков в MS-DIAL не выполняется.** Принудительное интегрирование вписывает в пропуски шум базовой линии, и «не обнаружено» становится неотличимым от «мало». Пропуски заполняются фреймворком после нормализации (п. 5.7), а влияние заполнения проверяется анализами чувствительности.
- **Нормализация в MS-DIAL не выполняется.** Нормализация по разведению (PQN) и коррекция межсерийного сдвига по QC выполняются фреймворком.

## 5.4. Запуск и контроль результатов MS-DIAL

1. Запустить обработку (Data processing → All processing).
2. Проверить выравнивание по 5–10 соединениям, присутствующим во всех образцах: креатинин, гиппуровая кислота, глюкурониды, ацилкарнитины. Каждое должно выравниваться одним пятном, без расщепления на несколько признаков с близким RT.
3. Наложить хроматограммы QC разных серий. Если серии сдвинуты по RT больше чем на 0.05–0.1 мин, увеличить допуск выравнивания по RT и повторить выравнивание.
4. Сохранить проект: файл .mdproject и папку проекта. Параметры (п. 5.3) экспортировать в текстовый файл и хранить вместе с результатами.

## 5.5. Экспорт

Export → Alignment result:

- **Raw data matrix (Area)** — площади без нормализации;
- **включить в экспорт QC и бланки;**
- если доступно — столбцы о наличии спектра MS/MS и параметрах совпадения с библиотекой (MS/MS assigned, Total score, Matched peaks). По ним автоматически определяется, подтверждена ли аннотация спектром MS/MS (уровень MSI 2);
- формат — текст с разделителем табуляцией.

Название файла: `<выборка>_alignment_area_<дата>.txt`.

## 5.6. Подготовка таблицы для фреймворка

Фреймворк принимает таблицу (`data/<выборка>_table.csv`), в которой:

- одна строка соответствует одной инъекции;
- первые столбцы — `Sample` (имя инъекции) и `Group` (BC / Control / PC / QC / Blank);
- далее по одному столбцу на признак с именем `RT_mz_название`, например `11.052_498.26974_low score: …`. Неподтверждённые аннотации MS-DIAL сохраняют префикс «low score:», неаннотированные признаки называются «Unknown».

Экспорт MS-DIAL содержит признаки в строках, а инъекции — в столбцах. Преобразование выполняет скрипт `tools/msdial_to_table.py`:

```
python tools/msdial_to_table.py <выборка>_alignment_area_<дата>.txt --out data/<выборка>/<выборка>_table.csv --sample-pattern "(\d+)$"
```

Скрипт выполняет следующее:

- находит в файле строку заголовков («Alignment ID», «Average Mz») и служебные строки MS-DIAL «Class», «File type», «Injection order», «Batch ID»;
- отбрасывает служебные столбцы и столбцы средних и SD по классам;
- транспонирует таблицу и формирует имена признаков «RT_mz_название» из исходных строк MS-DIAL без переформатирования чисел;
- сохраняет инъекции QC и бланков.

Параметр `--sample-pattern` задаёт, как из имени файла получить номер образца (например, `urine_s_07` → `7`). Если служебных строк в экспорте нет, QC и бланки распознаются по имени (`QC…`, `Blank…`).

Рядом с таблицей скрипт создаёт три файла:

- `<выборка>_table_injections.csv` — журнал инъекций из проекта MS-DIAL: тип, класс, серия, порядок;
- `<выборка>_table_metadata_template.csv` — заготовку файла метаданных; пол и возраст заполняются вручную, затем файл переносится в `metadata/`;
- `<выборка>_table_ms2.csv` — сведения о совпадении спектров MS/MS. Признаки с «MS/MS matched = True» используются для присвоения уровня MSI 2.

Контроль: число признаков и инъекций каждого типа, выведенное скриптом, совпадает с проектом MS-DIAL.

## 5.7. Обработка во фреймворке

1. Поместить таблицу в `data/`, метаданные — в `metadata/`.
2. В `pipeline/config.py` описать набор данных, по образцу набора `s107`:
   - пути к таблице и метаданным;
   - группы и сравнения;
   - серии (`BATCHES`) и шаг QC (`QC_EVERY`);
   - члены экзогенного гомологического ряда с временами удерживания для этих данных (`curation_<выборка>/contaminant_series.csv`).
3. Запуск:

```
METAB_DATASET=<выборка> python run_all.py
```

Фреймворк выполняет:

- фильтры детекции и RSD;
- коррекцию межсерийного сдвига по QC;
- проверку дрейфа;
- нормализацию PQN;
- **заполнение пропусков половиной минимума признака** и log₂-преобразование;
- объединение ионов в соединения;
- оценку происхождения сигналов и расчёт индекса экзогенного сигнала;
- статистический анализ, правило отбора находок и классификационные модели;
- анализы чувствительности.

Все шаги и их численные итоги записываются в `results_<выборка>/log.txt`.

4. Если бланки есть в таблице, дополнительно выполнить проверку членов экзогенного ряда по хроматограммам выделенных ионов (`blank_check.py`) и анализы чувствительности:

```
python blank_check.py
python sensitivity_index.py
python sensitivity_imputation.py
```

# 6. Контроль качества и критерии приемлемости

Таблица 2 — Критерии приемлемости

| Показатель | Где смотреть | Критерий | Действие при несоответствии |
|---|---|---|---|
| Медианное RSD признаков в QC (после фильтра ≤ 30 %) | log.txt, рис. качества данных | ≤ 15 % | проверить выравнивание и серии; при сохранении — пересмотреть пробоподготовку |
| Доля признаков, прошедших фильтр RSD | log.txt | ≥ 70 % прошедших фильтр детекции | то же |
| Различия QC между сериями после коррекции | log.txt | 0 признаков с q < 0.05 | проверить назначение серий и QC |
| Дрейф внутри серии (leave-one-QC-out) | log.txt | LOWESS уменьшает ошибку < 20 % → коррекция не нужна | при большем выигрыше включить `DRIFT = "lowess"` |
| Положение QC на проекции главных компонент | рис. качества данных | QC компактны и в центре образцов | проверить выбросы QC, отдельные инъекции |
| Образцы с коэффициентом PQN < 0.2 | log.txt | перечислены и проверены по хроматограммам | при технической ошибке — исключить с указанием причины |
| Члены экзогенного ряда в бланках | blank_check | отношение бланк/QC указано для каждого члена | индекс из членов, отсутствующих в бланках, — анализ чувствительности |

# 7. Записи и хранение

Сохраняются:

- исходные файлы .raw (неизменяемые);
- журнал последовательности;
- проект и параметры MS-DIAL;
- файл экспорта;
- таблица для фреймворка;
- метаданные;
- папка результатов `results_<выборка>/` с файлом `log.txt`;
- версия кода (коммит репозитория), с которой получены результаты.

Изменения параметров вносятся только через `pipeline/config.py` и фиксируются в истории репозитория.

# 8. Типичные ошибки

| Ошибка | Последствие | Как избежать |
|---|---|---|
| Не указаны серии и порядок инъекций в MS-DIAL и журнале | невозможно оценить дрейф и межсерийный сдвиг | заполнять журнал до начала измерений (п. 4.2) |
| Бланки и QC не включены в экспорт | невозможны фильтр по бланкам и проверка экзогенных сигналов во фреймворке | экспортировать все инъекции (п. 5.5) |
| Включено принудительное заполнение пропусков в MS-DIAL | шум вместо «не обнаружено», искажение сравнения групп | Gap filling — выключено |
| Повторяющиеся имена бланков или QC | неверное назначение серий | уникальная сквозная нумерация (п. 4.1) |
| Выравнивание по образцу с нетипичным составом | расщепление признаков | референс — QC |
| Нет аддуктов [M+NH₄]⁺ и [M+H−H₂O]⁺ | конъюгаты не связаны со своими ионами в MS-DIAL | перечень аддуктов по табл. 1 |
| Аннотация принята без проверки формулы и иона | неверная идентификация (несоответствие m/z, изобары) | проверка во фреймворке, курация кандидатов, уровни MSI |
