# Ненаправленное метаболомное профилирование мочи (ВЭЖХ-МС), батч s266

РМП (рак мочевого пузыря, BC) и РПЖ (рак предстательной железы, PC) против контроля. Вся обработка выполняется одним запуском, параметры задаются правилами (без ручных подвыборок).

## Запуск
```bash
pip install -r requirements.txt
python make_metadata.py      # один раз: metadata/metadata.csv из листа последовательности (уже создан)
# … правка metadata/metadata.csv (возраст, пол, include) …
python run_all.py            # вся обработка, results/ пересоздаётся; в конце строятся публикационные рисунки
python run_all.py --quick    # быстрая проверка (20 перестановок, без путей)
python make_figures.py       # только перестроить рисунки для журнала по готовым results/
```

## Обработка (`run_all.py`, модули `pipeline/`)
1. **Фильтры:** детекция ≥ 80 % в QC и ≥ 50 % хотя бы в одной группе (14 693 → 8 867); фильтр по бланкам (QC/бланк ≥ 5) — **применяется автоматически, если в таблице есть бланки** (сейчас их нет); RSD в QC ≤ 30 % (→ 7 403).
2. **Без коррекции дрейфа.** Проверка leave-one-QC-out: |Δlog2| 0.081 без коррекции против 0.074 с LOWESS — выигрыш пренебрежим. Медианный RSD QC 10.4 % до RSD-фильтра, 8.6 % после.
3. **Нормализация:** основная PQN; параллельно MSTUS (1 900 признаков, обнаруженных во всех пробах). Пробы с PQN-фактором < 0.2 (13, 17, 23, 29, 36, 39, 40) перечислены в `low_dilution_samples` для просмотра хроматограмм; анализ чувствительности без них — в `normalization_sensitivity`.
4. **Импутация** ½ минимума (11.8 % значений); доля импутации по группам — в `features` (`imputed_*`). Признаки «есть/нет» (детекция < 50 % в одной группе и ≥ 80 % в другой; 41 шт.) — отдельный лист с точным тестом Фишера.
5. **Группировка признаков в соединения:** ΔRT ≤ 0.02 мин и корреляция Спирмена ≥ 0.8; разности масс аддуктов/изотопов/потерь подписаны (`ion_relations`). 7 403 признака → 5 792 соединения; статистика и FDR считаются по соединениям (один представитель).
6. **Индекс загрязнения** — средний z-score 10 признаков ряда алкилдиэтаноламинов; high/low по медиане. Средние: контроль −0.37, РМП −0.02, РПЖ +0.87. C24H30O6 показывается отдельно.
7. **Категории:** контаминант / лекарство / табак / пища (по курации и ключевым словам). Аннотации с low score на рисунках показываются как `unknown` (название — только в таблице). Экспозиции не бывают «находками» и не входят в панели и пути.

## Статистика
Для каждого сравнения — **РМП vs контроль (основное), РМП vs РПЖ, РПЖ vs контроль, РПЖ vs мужчины-контроли**:
* основная модель `log2 ~ группа + пол + возраст + индекс загрязнения` (complete case) → `beta_model`, `q_model` (BH);
* подбор по возрасту: 1:1, ближайший возраст, допуск ±5 лет, внутри пола (оптимальное назначение) → `p_matched`; число пар — в `summary_univariate`;
* для сравнений с контролем: case vs контроли с **низким** индексом (`p_lowindex`) и контроли high vs low (`p_ctrl_hi_vs_lo`).

**Правило находки:** q_model < 0.05 **и** p_matched < 0.05 в том же направлении; для сравнений с контролем дополнительно p_lowindex < 0.05 в том же направлении **и** p_ctrl_hi_vs_lo ≥ 0.05; экспозиции исключены.

| сравнение | n (в модели) | пар по возрасту | q_model < 0.05 | находки |
|---|---|---|---|---|
| РМП vs контроль | 29/45 (29/39) | 18 | 295 | 212 |
| РМП vs РПЖ | 29/20 (29/20) | 18 | 3 | 3 |
| РПЖ vs контроль | 20/45 (20/39) | 9 | 0 | 0 |
| РПЖ vs мужчины-контроли | 20/18 (20/17) | 9 | 0 | 0 |

**Сигнал РПЖ после поправки на возраст и загрязнение не сохраняется.** Индекс загрязнения сам по себе отличает РПЖ от контроля с AUC 0.87 (от мужчин-контролей — 0.94).

### Классификация без утечки (`multivariate_CV`, рис. Figure5)
20 × 5-fold CV, top-5 признаков (Манн–Уитни) отбираются **внутри обучающего фолда**, логистическая регрессия; PLS-DA — на всех соединениях без экспозиций; 1000 перестановок.

| сравнение | все пробы, AUC (perm p) | подбор по возрасту | только пол | только индекс |
|---|---|---|---|---|
| РМП vs контроль | 0.81 ± 0.03 (0.001); с поправкой на загрязнение 0.78 ± 0.05 (0.002) | 0.71 ± 0.05 (18 пар, p 0.059); по загрязнению 0.71 ± 0.07 (15 пар, p 0.073) | 0.65 | 0.59 |
| РМП vs РПЖ | 0.86 ± 0.04 (0.002); с поправкой 0.63 ± 0.07 (0.11) | 0.78 ± 0.05 (18 пар, p 0.021); по загрязнению 0.57 ± 0.06 (13 пар, p 0.28) | 0.55 | 0.78 |
| РПЖ vs контроль | 0.54 ± 0.06 (0.35); с поправкой 0.74 ± 0.07 (0.012) — **не интерпретируется**, см. ниже | не оценивается (9 и 5 пар) | 0.75 | 0.86 |

Базовые модели «только пол» и «только индекс» считаются **той же** повторной CV (логистическая регрессия на одной ковариате) с тем же перестановочным тестом. Подбор пар по индексу загрязнения (1:1 внутри пола, допуск 0.25 SD) — анализ чувствительности, `contam_matched_pairs`.

*Почему у РПЖ vs контроль AUC растёт после поправки (0.54 → 0.74).* Утечки меток нет: коэффициенты поправки оцениваются только на обучающем фолде; на случайном шуме процедура даёт 0.45, при перемешанном индексе — 0.58. Рост возникает только с настоящим индексом, который почти разделяет группы (AUC 0.86): «скорректированная» разница — экстраполяция наклона через разрыв между группами, и часть различия по индексу переносится в признаки. Подтверждения: у РПЖ vs мужчины-контроли прироста нет (0.62 → 0.61); при оценке наклона внутри групп (как в ANCOVA) AUC доходит до 0.85 — уровня самого индекса; в скорректированной одномерной модели нет ни одного соединения с q < 0.05.

*Почему ранее было «0.84 на ROC против 0.807 в таблице»:* в старой версии ROC-кривая строилась по одному разбиению CV (seed 1), а в таблице было среднее по 5 повторам. Сейчас и кривая, и таблица — среднее по 20 повторам с одинаковыми seed.

### Нормализация и чувствительность
PQN и MSTUS отличаются только множителем на пробу (ρ log2FC = 1.00). РМП vs контроль: значимых 295 (PQN) и 203 (MSTUS, все входят в 295); находок 212 и 125 (общих 120); AUC панели 0.81 и 0.80. Пробы с PQN-фактором < 0.2 (3 РМП, 3 РПЖ, 1 контроль) **оставлены** в основном анализе; без них: значимых 490 (277 общих), находок 371 (190 из 212 сохраняются), AUC панели 0.80.

### Курированные кандидаты (`candidates_curated`)
* Уровень MSI — одно правило и один источник для Table 2, рисунков и Table S4 (`make_figures.msi_levels`): 1 — стандарт; 2 — курированная формула (≤ 5 ppm) и флаг MS2 MS-DIAL у самого признака, без неразличимых изомеров (изомеры, которые MS2 не различает, перечислены в `isomers_note`); 3 — формула без MS2, неразличимые изомеры или MS2 без курации; 4 — остальное, ошибка массы > 5 ppm и `annotation_exclusions.csv`. Оценки совпадения (score) MS-DIAL в экспорте нет — используется флаг идентификации.
* 9 аннотаций с ошибкой массы > 5 ppm (включая 5-гидроксиомепразол, −6 ppm) — на отдельном листе с HMDB-альтернативами в пределах 3 ppm.
* Стероид C19H28O3 (11-оксоэтиохоланолон / изомеры, MSI 3): ионы [M+H−H2O]⁺ 287.2007 и [M+H−2H2O]⁺ 269.1901 при одном RT (ρ = 0.99); MS2 совпадает с двумя изомерами в библиотеке.
* Из 212 находок РМП: MSI 2 — 4 (додеканоилкарнитин, биливердин, LPC 16:0, Val-Leu), MSI 3 — 3 (стероид C19H28O3 и два изомерных глюкуронида тетрагидрокортизона: [M+H]⁺ 541.2642 и [M+NH4]⁺ 558.2914, при одном RT — агликоновые ионы с MS2 тетрагидрокортизона), MSI 4 — 205 (в т. ч. этил-2-амино-5-метил-3-тиофенкарбоксилат — синтетический реагент, совпадение по in-source фрагменту).
* LPC 16:0 и 18:1 связаны с индексом загрязнения (ρ = 0.21 и 0.34) и обратно — с фактором разведения. Биливердин связан с фактором разведения (ρ = 0.25). Находками они не являются.

## Сверка с первым этапом (статья ABC: Frolova et al., Anal Bioanal Chem 2026, doi:10.1007/s00216-026-06678-w)
14 маркеров из Table 5 статьи (`curation/prior_markers.csv`) ищутся в полной таблице признаков: m/z ± 5 ppm от опубликованного **или** теоретического значения (формула + ион) и RT ± 0.5 мин. Показываются все изомерные кандидаты. **Окно по RT пока не обосновано данными:** нужен список соединений с MS2-идентификацией на первом этапе (`curation/rt_anchors_stage1.csv`: compound, mz, rt_stage1); тогда `run_all.py` посчитает медиану, IQR и диапазон сдвига RT (лист `rt_shift_anchors`). Среди найденных маркеров ΔRT от −0.43 до +0.19 мин — этого мало для обоснования.

Результат:
* 7 маркеров не обнаружены;
* 2 обнаружены ниже порога детекции (Leu-Leu-Arg, 2-иминобиотин);
* 5 измерены (5-гидроксиомепразол — только по теоретическому m/z, без различий между группами):
  * Val-Leu — два изомера; признак при 3.72 мин повышен при РМП (AUC 0.76, p = 1.4·10⁻⁴), значим после поправок (q = 0.048) и при подборе по возрасту (p = 0.004), MSI 2;
  * глутаминилпролин и LysoPE(20:4) — то же направление, незначимо;
  * Leu-Thr-Ser — обратное направление.

Воспроизведён 1 маркер из 14 — Val-Leu (Figure 6, Table S3).

В Table 5 статьи есть несоответствия, их нужно проверить:
* у N-ацетилтриптофана указан m/z 249.0923 вместо [M+H]⁺ 247.108;
* у 5-гидроксиомепразола m/z расходится с теоретическим на +22 ppm;
* у Leu-Leu-Tyr и Leu-Thr-Ser неверные формулы.

## Чего нельзя сделать без лабораторных данных
* **Бланки:** по методике фильтр по бланкам (проба/бланк ≥ 5) выполнен в MS-DIAL, поэтому в экспортированной таблице бланков нет. Если бланки добавить в таблицу как пробы `Blank…`, пайплайн применит фильтр повторно. Бланк пустого контейнера по-прежнему полезен для подтверждения происхождения ряда диэтаноламинов.
* **Хроматограммы** проб с низким фактором разведения: решение записать в `metadata.csv` (`include` / `exclude_reason`).
* **MS2 score**: если экспортировать из MS-DIAL выравнивание со столбцами Total score / Dot product, их можно добавить в Table S4.
* **Сдвиг RT между этапами**: `curation/rt_anchors_stage1.csv` (см. выше).
* **Возраст** 4 контролей и пол 2 контролей — в `metadata_stage2.csv` (сейчас эти участники исключаются из скорректированной модели).
