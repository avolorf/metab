# s107 (этап 1): клинические подгруппы внутри РМП — блок Б

## Данные и выборка
* **Матрица.** Та же, что в основном анализе s107. Предобработка: межсерийная коррекция по QC, фильтры детекции и
  RSD в QC, PQN, импутация ½ минимума, log₂, объединение ионов в соединения, индекс экзогенного сигнала. Опубликованные
  числа основного анализа воспроизведены без изменений: 3603 соединения, 104 пробы.
* **Выборка.** Только РМП, 64 пробы. Клинические подгруппы сопоставлены по номеру пробы, шифр, группа и возраст сверены.
* **Сравнения.**
  * **S1, стадия:** T1 (n = 28) против Ta (n = 22). Подгруппы T2plus, ambiguous, unknown и PUNLMP_uncertain показаны
    только описательно.
  * **S2, степень злокачественности:** HG (n = 21) против LG (n = 34). Подгруппы G2_1973, not_stated и
    PUNLMP_uncertain исключены.
* **Исключённые соединения.** 144 соединения (331 признак), которые анализируются отдельно, в этот блок не входят.

## Модель
* **Основная модель** для каждого соединения: `log₂ ~ подгруппа + пол + возраст + индекс экзогенного сигнала`.
  Коэффициент подгруппы — это log₂FC; для него даются 95 % ДИ и p.
* **S2 с поправкой на стадию:** только пробы Ta и T1 (12 HG / 33 LG), в модель добавлена стадия. Возраст в этом
  варианте задан ограниченным кубическим сплайном с узлами 45, 67 и 82 года: HG в среднем на 11 лет старше LG.
* **Анализ чувствительности:** только мужчины, `log₂ ~ подгруппа + возраст + индекс`. Пары по полу и возрасту не
  строились, так как в подгруппах мало женщин.
* **AUC** — вероятность того, что значение в первой подгруппе больше, чем во второй. Считается по log₂ без поправок,
  95 % ДИ — стратифицированный бутстрэп (2000 повторов).
* **Тренд Контроль → Ta → T1** — критерий Йонкхира–Терпстры, перестановочный p (10 000 перестановок). Мера эффекта —
  доля согласованных пар с 95 % ДИ: 0,5 — тренда нет, 1 — все пары упорядочены по возрастанию.
* **Начальное значение генератора:** 20261013. Все параметры записаны в `parameters.json`.

## Результаты
**Описательная таблица** (`descriptive_subgroups.csv`, `descriptive_tests.csv`, `stage_by_grade.csv`).
* Ta и T1 не различаются по возрасту (p = 0,38), полу (p = 1,0) и индексу (p = 0,49).
* HG старше LG: медиана 75 против 64 лет, p = 0,004. По полу (p = 0,72) и индексу (p = 0,28) различий нет.

**«Пептидная» оценка** — среднее z-оценок 54 пептидов, повышенных при РМП в основном анализе
(`peptide_score_compounds.csv`):

| вариант | n | разность, z [95 % ДИ] | p | AUC [95 % ДИ] |
|---|---|---|---|---|
| S1: T1 против Ta | 28/22 | +0,10 [−0,23; 0,43] | 0,55 | 0,63 [0,46; 0,78] |
| S1, только мужчины | 23/18 | +0,05 [−0,33; 0,43] | 0,79 | 0,61 [0,42; 0,79] |
| S2: HG против LG | 21/34 | +0,52 [0,15; 0,90] | 0,007 | 0,76 [0,63; 0,88] |
| S2 с поправкой на стадию (возраст — сплайн) | 12/33 | +0,22 [−0,28; 0,72] | 0,38 | 0,71 [0,53; 0,87] |
| S2, только мужчины | 17/29 | +0,42 [−0,01; 0,84] | 0,054 | 0,72 [0,57; 0,87] |
| S2 с поправкой на стадию, только мужчины | 9/28 | +0,21 [−0,40; 0,82] | 0,49 | 0,66 [0,44; 0,85] |

* **Тренд Контроль → Ta → T1:** доля согласованных пар 0,89 [0,86; 0,93], p < 0,001; у мужчин 0,84 [0,77; 0,92].
  Тренд создаёт разница «контроль против РМП»: между Ta и T1 различий нет.
* **Связь с HG** есть только без поправки на стадию; с поправкой она слабеет и незначима.

**Ненаправленное сравнение** (поправка Бенджамини–Хохберга по 3459 соединениям; `untargeted_summary.csv`).
* Ни в S1, ни в S2, ни в одном варианте модели нет соединений с q < 0,05.
* Наименьшее q: S1 — 0,35, S2 — 0,09, S2 с поправкой на стадию — 0,75.
* В `untargeted_S1_top.csv` и `untargeted_S2_top.csv` — первые 50 соединений по p. В файлах `*_all_compounds.csv` —
  все соединения со всеми вариантами модели.

**Классификация S1 (T1 против Ta)** — вложенная перекрёстная проверка, 5 блоков × 20 повторов
(`classification_S1_nested_cv.csv`).
* **Отбор признаков** — только по обучающим пробам. Размер панели (k ∈ {3, 5, 10, 20}) и число компонент PLS-DA
  (1–3) выбирает внутренняя 5-блочная CV.
* **Пул:** 3224 соединения. Исключены экспозиции (лекарства, пища, табак) и соединения с |ρ| ≥ 0,5 с индексом
  экзогенного сигнала.
* **Перестановочный тест:** на каждую из 1000 перестановок повторяется вся процедура CV.

| модель | AUC (среднее по 20 повторам) | 2,5–97,5 % | перестановочный p |
|---|---|---|---|
| панель top-k (Манн–Уитни + логистическая регрессия) | 0,51 | 0,44–0,60 | 0,38 |
| PLS-DA | 0,57 | 0,48–0,70 | 0,23 |
| базовая модель «пол + возраст» | 0,48 | 0,39–0,53 | 0,46 |

Метаболомный профиль мочи не различает стадии Ta и T1. Частота отбора соединений в панель —
`classification_S1_panel_selection_frequency.csv`, ROC — `Figure_classification_S1_ROC`.
