# s107: клинические подгруппы внутри РМП

Переобработка этапа 1 (выборка s107, 107 проб) по стадии и степени злокачественности рака мочевого пузыря.

## Входные данные
* Клинические подгруппы: `s107_clinical_groups.xlsx` (кладётся в `input/`, в git не входит). Пробы сопоставляются
  по `sample_no`. Шифр (`code`), группа и возраст сверяются с `metadata/metadata_s107.csv` основного анализа, при
  расхождении расчёт останавливается. Пол берётся из основного анализа (v2). У проб 35 и 86 в клиническом файле
  указан мужской пол, в основном анализе он исправлен на женский после сверки. Сверка по каждой пробе — в
  `results_s107_clinical/sample_reconciliation.csv`.
* Матрица: та же, что в основном анализе s107 (коррекция серий по QC, фильтры, PQN, импутация ½ минимума, log₂,
  объединение ионов в соединения, индекс экзогенного сигнала). `prepare_matrix.py` строит её кодом основного
  конвейера (ветка `claude/metabolomics-hplc-ms-processing-ktvooo`, коммит 97dffcb) и проверяет, что совпадают все
  опубликованные числа: 12 930 → 5 887 → 4 730 признаков → 3 603 соединения, 104 пробы, 918 соединений с q < 0,05 и
  582 находки в сравнении РМП с контролем. При любом расхождении расчёт останавливается.

## Запуск
```bash
# копия ветки основного анализа с таблицей data/s107/s107_table.csv (не в git)
git worktree add ../s107_main origin/claude/metabolomics-hplc-ms-processing-ktvooo
export S107_PIPELINE=../s107_main
python make_peptide_candidates.py                     # кандидаты для «пептидной» оценки
python run_clinical.py --clinical input/s107_clinical_groups.xlsx \
    [--peptide_list peptide_score_list.csv] [--n_perm 1000] [--skip_classification]
```
Зависимости — `requirements.txt` основного конвейера. Начальное значение генератора — `SEED` основного анализа
(20261013). Все параметры записываются в `parameters.json`.

## Сравнения и модель
* **S1, стадия:** T1 (n = 28) против Ta (n = 22). Подгруппы T2plus, ambiguous, unknown и PUNLMP_uncertain показаны
  только описательно.
* **S2, степень злокачественности:** HG (n = 21) против LG (n = 34). Подгруппы G2_1973, not_stated и
  PUNLMP_uncertain исключены.
* **Модель** для каждого соединения: `log2 ~ подгруппа + пол + возраст + индекс`. Коэффициент подгруппы — это log₂FC;
  для него даются 95 % ДИ (t-распределение) и p.
* **Вариант S2 с поправкой на стадию:** только пробы Ta/T1, в модель добавлена стадия (T1 против Ta).
* **Анализ чувствительности:** только мужчины, `log2 ~ подгруппа + возраст + индекс`. Пары по полу и возрасту не
  строятся.
* **AUC** = P(case > ref) по log₂ без поправок; 95 % ДИ — стратифицированный бутстрэп, 2000 повторов.
* **Тренд Контроль → Ta → T1:** критерий Йонкхира–Терпстры; p асимптотический (с поправкой на связи) и
  перестановочный (10 000 перестановок).

## Результаты (`../results_s107_clinical/`)
| папка / файл | содержание |
|---|---|
| `steroids/` (блок А, только для руководителя) | три глюкуронида стероидов: модели S1/S2 (q по BH только по этим трём соединениям), ионы агликонов и аддукты для проверки, тренд, описательная статистика по всем подгруппам, рисунок |
| `clinical/` (блок Б, без стероидов) | описательная таблица; ненаправленное сравнение S1 и S2 (BH по всем соединениям блока Б); классификация S1; «пептидная» оценка |
| `excluded_steroid_features_for_block_B.csv` | признаки, исключённые из блока Б: три глюкуронида со всеми ионами и все соединения, у иона которых аннотация стероида или стероидного конъюгата; класс указан (гормон, желчная кислота, экдистероид) |
| `peptide_score_candidates.csv` | кандидаты в «пептидную» оценку; утверждённый список — `s107_clinical/peptide_score_list.csv` (54 пептида: находки основного анализа без биливердина и четырёх синтетических аннотаций) |
| `sample_reconciliation.csv`, `parameters.json`, `log.txt` | сверка проб, параметры, журнал |

**Классификация S1.** Внешняя CV — 5 блоков × 20 повторов. Внутри каждого обучающего блока работает внутренняя 5-fold
CV: она выбирает размер панели (top-k по Манн–Уитни, k ∈ {3, 5, 10, 20}) с логистической регрессией или число
компонент PLS-DA (1–3). Признаки отбираются только на обучающих пробах.
* Пул соединений собран по тем же правилам, что в основном анализе: без экспозиций и без соединений с |ρ| ≥ 0,5 с
  индексом. Стероиды из пула тоже исключены.
* Базовая модель: «пол + возраст».
* Перестановочный тест: на каждую из 1000 перестановок меток повторяется вся процедура CV.
