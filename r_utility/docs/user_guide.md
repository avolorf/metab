### Установка

1. Установите R версии 4.0.0 или новее (Windows: https://cran.r-project.org/bin/windows/base/), при установке оставьте параметры по умолчанию.
2. Распакуйте архив `UroMetabR_v1.0.0_….zip` в любую папку (например, `C:\UroMetabR`).
3. Дважды щёлкните `Start_UroMetabR.bat`. При первом запуске недостающие пакеты CRAN устанавливаются автоматически (нужен интернет, 5–15 минут), затем в браузере открывается окно программы. Следующие запуски занимают несколько секунд.
4. Чтобы запускать программу с рабочего стола, один раз дважды щёлкните `Create_desktop_shortcut.vbs`.
5. Для обработки сырых данных mzML/mzXML/CDF дополнительно один раз выполните в R: `install.packages("BiocManager"); BiocManager::install(c("xcms", "MSnbase", "IPO"))`.

Чек-лист испытания установки (п. 10): записать версию Windows и R, время от распаковки до открытия окна программы, сообщения об ошибках; затем открыть проект с контрольным набором и выполнить модули 0–9.

### Порядок работы

1. **Папка проекта.** Укажите пустую или существующую папку и нажмите «Открыть / создать проект». В ней появится файл настроек `settings.yaml`; результаты каждого модуля сохраняются в подпапки `00_input` … `09_report`, журналы и сведения о версиях R и пакетов — в `logs`.
2. **Данные.** Выберите тип входных данных:
   * готовая таблица признаков — CSV, TSV или TXT (строки — инъекции, первый столбец — имя файла/инъекции, остальные — признаки; имена признаков вида `mz / RT`, `RT_mz_имя` или экспорт выравнивания MS-DIAL); модуль 1 при этом пропускается;
   * сырые данные — папка с файлами mzML, mzXML или CDF (нужен Bioconductor-пакет xcms).
3. **Метаданные** — таблица CSV, по строке на файл (инъекцию):

   | столбец | обязательный | содержание |
   |---|---|---|
   | file | да | имя файла или строки таблицы |
   | group | да | группа (например, CG, BC); QC — для образцов контроля качества, Blank — для бланков |
   | sample | нет | код образца; у повторных вводов одного образца он одинаковый (повторы усредняются) |
   | injection_order | нет | порядок ввода |
   | replicate | нет | номер повтора |
   | include | нет | 0 — исключить образец |
   | sex, age | нет | пол (M/F) и возраст — для модели с поправкой на них |

4. Нажмите **«Проверить данные»**: модуль 0 сообщит о несовпадении имён, отсутствующих столбцах, доле пропусков и числе образцов QC.
5. **Параметры** менять не обязательно: значения по умолчанию соответствуют методике. После изменения нажмите «Сохранить настройки».
6. **Запуск.** Выберите модули (по умолчанию 0–9) и нажмите «Запустить обработку». Журнал обновляется каждую секунду; таблица показывает время и память по модулям. Модуль можно перезапустить отдельно: предыдущие результаты берутся из папки проекта.
7. **Результаты.** «Открыть отчёт» — HTML-отчёт со всеми таблицами, рисунками, журналом и версиями пакетов. Таблицы — в CSV (открываются в Excel), рисунки — PNG и JPEG.

### Как читать результаты

* **Профили фильтра (модуль 3).** Стандартный (по умолчанию) — для анализа и отбора маркеров: признак должен присутствовать хотя бы в половине образцов одной из групп. Строгий — для базы признаков: сигнал обнаружен во всех образцах и стабилен в QC (RSD ≤ 15 %); такие признаки пригодны для накопления между когортами. Шаги обоих профилей — в `03_filter/filter_steps.csv`.
* **ds, ds_d, ds_rfe** — признаки после одномерного фильтра (ОСФ), после отбора по частоте встречаемости в четырёх моделях (СПФ) и после рекурсивного отбора (РОП).
* **Средняя AUROC по этапам** — описательная величина: признаки отобраны по тем же данным, поэтому она растёт по построению.
* **Вложенная кросс-валидация** — несмещённая оценка точности: весь отбор повторяется только на обучающей части и проверяется на отложенных образцах.
* **База признаков** (`features_db`) пополняется при каждом прогоне: `runs_db.csv` — прогоны, `features_db.csv` — признаки с m/z, RT и отметками отбора, `intensities_db.csv` — интенсивности.

### Если что-то не так

* «Не найден файл…» — проверьте путь; пути можно указывать относительно папки проекта.
* «Слишком мало совпадений имён» — значения столбца `file` метаданных должны совпадать с первым столбцом таблицы (или с именами файлов без расширения).
* «Меньше двух признаков после ОСФ» — поправка Холма строгая; выберите поправку BH в параметрах.
