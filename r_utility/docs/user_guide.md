### Установка (Windows, без навыков программирования)

Понадобится: компьютер с Windows 8 или новее, процессор от 2,5 ГГц, оперативная память от 8 ГБ, 1 ГБ свободного места на диске, подключение к интернету (только при первом запуске), браузер (Edge, Chrome, Firefox или Яндекс Браузер). Права администратора не обязательны.

**Шаг 1. Установите R** (один раз; если R версии 4.0.0 или новее уже установлен, шаг можно пропустить).
1. Откройте в браузере https://cran.r-project.org/bin/windows/base/ и нажмите ссылку «Download R-4.x.x for Windows» (x — номер текущей версии). Рекомендуется R 4.2 или новее.
2. Запустите скачанный файл `R-4.x.x-win.exe`. Если Windows спросит «Разрешить этому приложению вносить изменения?» — нажмите «Да» (если прав администратора нет, нажмите «Нет»: установщик предложит установить R только для вас — это тоже подходит).
3. Во всех окнах установщика оставьте значения по умолчанию и нажимайте «Далее», в конце — «Завершить».

RStudio для работы программы не нужна.

**Шаг 2. Распакуйте архив программы.**
1. Скопируйте архив `UroMetabR_v1.0.0_2026-10-27.zip` в удобное место, например на диск `C:` или в «Документы».
2. Щёлкните архив правой кнопкой мыши → «Извлечь все…» → «Извлечь». Запускать файлы прямо из окна архива нельзя — сначала распакуйте.
3. Рекомендуется папка без русских букв и пробелов в пути, например `C:\UroMetabR`.

**Шаг 3. Первый запуск.**
1. Откройте распакованную папку, затем папку `r_utility`, и дважды щёлкните файл `Start_UroMetabR.bat` (в Проводнике он может отображаться как `Start_UroMetabR` с типом «Пакетный файл Windows»).
2. Если появится окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае». Это предупреждение появляется для всех файлов, скачанных из интернета.
3. Откроется чёрное окно (консоль). При первом запуске программа сама скачивает и устанавливает нужные пакеты R — это занимает 5–15 минут, в окне идут строки с названиями пакетов. Дождитесь окончания.
4. Затем автоматически откроется браузер с окном программы (адрес вида `http://127.0.0.1:…`). Следующие запуски занимают несколько секунд.
5. **Не закрывайте чёрное окно**, пока работаете с программой: его закрытие завершает работу UroMetabR. Чтобы выйти из программы, закройте вкладку браузера и чёрное окно.

**Шаг 4. Ярлык на рабочем столе (по желанию).** Дважды щёлкните `Create_desktop_shortcut.vbs` в той же папке — на рабочем столе появится ярлык «UroMetabR». Дальше программу можно запускать с него.

**Шаг 5. Только для сырых данных mzML/mzXML/CDF (по желанию).** Для готовых таблиц (CSV, TSV, TXT, экспорт MS-DIAL) этот шаг не нужен.
1. Откройте меню «Пуск» → «R» → «R 4.x.x» (в старых версиях — «R x64 4.x.x»). Откроется окно R с приглашением `>`.
2. Скопируйте строку ниже, вставьте её в окно R (правая кнопка мыши → «Вставить» или Ctrl+V) и нажмите Enter:

       install.packages("BiocManager"); BiocManager::install(c("xcms", "MSnbase"))

3. Если R спросит про выбор зеркала — выберите любое (например, первое) и нажмите «ОК». На вопрос `Update all/some/none? [a/s/n]` введите `n` и нажмите Enter. Если спросит «Would you like to use a personal library instead?» — ответьте `yes`.
4. Установка занимает 10–30 минут. Когда снова появится приглашение `>`, закройте окно R (на вопрос о сохранении рабочего пространства ответьте «Нет»).

### Проверка установки (чек-лист, испытание 10)

В архиве есть контрольный набор `r_utility/example` (синтетические данные: 106 образцов в двух группах, 8 образцов QC, 600 признаков).
1. Запустите программу (шаг 3). На вкладке вверху в поле «Папка проекта» введите, например, `C:\UroMetabR_проверка` и нажмите «Открыть / создать проект».
2. На вкладке «1. Данные» нажмите «Выбрать…» рядом с «Файл таблицы признаков» и выберите `r_utility\example\peak_table.csv`; рядом с «Файл метаданных» — `r_utility\example\metadata.csv`.
3. Нажмите «Проверить данные (модуль 0)»: должна появиться таблица проверок, в строке «Таблица признаков» — «124 инъекций × 600 признаков».
4. Перейдите на вкладку «3. Запуск», нажмите «Запустить обработку» и дождитесь надписи «Обработка завершена» (около 5 минут).

### Если при установке что-то не так

| Сообщение или ситуация | Что делать |
|---|---|
| В чёрном окне: «R не найден» | R не установлен или установлен в нестандартную папку — выполните шаг 1 и запустите файл снова |
| «Не удалось установить пакеты…» | Нет доступа к интернету или его блокирует прокси-сервер организации — подключитесь к другой сети или обратитесь к системному администратору (нужен доступ к https://cloud.r-project.org), затем запустите файл снова |
| Чёрное окно сразу закрывается | Запустите `Start_UroMetabR.bat` ещё раз и сфотографируйте текст в окне до закрытия; проверьте, что архив распакован (шаг 2) |
| Браузер не открылся | Найдите в чёрном окне строку `Listening on http://127.0.0.1:…`, скопируйте адрес и вставьте его в адресную строку браузера |
| Кнопка «Выбрать…» не открывает окно выбора файла | Окно может открыться позади браузера — проверьте панель задач. Можно также нажать «Файл…» в поле «или загрузить» (файл скопируется в папку проекта) или вставить путь к файлу в поле вручную |
| Отчёт открывается без оформления | Это нормально без RStudio: отчёт формируется встроенным генератором, содержимое то же |

### Порядок работы

1. **Папка проекта.** Укажите пустую или существующую папку и нажмите «Открыть / создать проект». В ней появится файл настроек `settings.yaml`; результаты каждого модуля сохраняются в подпапки `00_input` … `09_report`, журналы и сведения о версиях R и пакетов — в `logs`.
2. **Данные.** Выберите тип входных данных:
   * готовая таблица признаков — CSV, TSV или TXT (строки — инъекции, первый столбец — имя файла/инъекции, остальные — признаки; имена признаков вида `mz / RT`, `RT_mz_имя` или экспорт выравнивания MS-DIAL); модуль 1 при этом пропускается;
   * сырые данные — папка с файлами mzML, mzXML или CDF (нужен Bioconductor-пакет xcms).
3. **Метаданные** — таблица CSV, по строке на файл (инъекцию):

   | столбец | обязательный | содержание |
   |---|---|---|
   | file | да | имя файла или строки таблицы |
   | group | да | группа (например, CG, BC); QC — для образцов контроля качества, Blank — для бланков |
   | sample | нет | код образца; у повторных вводов одного образца он одинаковый (повторы усредняются) |
   | injection_order | нет | порядок ввода |
   | replicate | нет | номер повтора |
   | include | нет | 0 — исключить образец |
   | sex, age | нет | пол (M/F) и возраст — для модели с поправкой на них |

4. Нажмите **«Проверить данные»**: модуль 0 сообщит о несовпадении имён, отсутствующих столбцах, доле пропусков и числе образцов QC.
5. **Параметры** менять не обязательно: значения по умолчанию соответствуют методике. После изменения нажмите «Сохранить настройки».
6. **Запуск.** Выберите модули (по умолчанию 0–9) и нажмите «Запустить обработку». Журнал обновляется каждую секунду; таблица показывает время и память по модулям. Модуль можно перезапустить отдельно: предыдущие результаты берутся из папки проекта.
7. **Результаты.** «Открыть отчёт» — HTML-отчёт со всеми таблицами, рисунками, журналом и версиями пакетов. Таблицы — в CSV (открываются в Excel), рисунки — PNG и JPEG.

### Как читать результаты

* **Профили фильтра (модуль 3).** Стандартный (по умолчанию) — для анализа и отбора маркеров: признак должен присутствовать хотя бы в половине образцов одной из групп. Строгий — для базы признаков: сигнал обнаружен во всех образцах и стабилен в QC (RSD ≤ 15 %); такие признаки пригодны для накопления между когортами. Шаги обоих профилей — в `03_filter/filter_steps.csv`.
* **Данные для отбора (модуль 7).** По умолчанию отбор выполняется на данных после заполнения пропусков и log2, без EigenMS. EigenMS подбирает тренды по тем же меткам групп, поэтому тесты на скорректированных данных занижают p-значения и дают ложные находки (на контрольном наборе В — 9 при поправке Холма и 188 при BH); EigenMS используется для визуализации и доступен как параметр.
* **ds, ds_d, ds_rfe** — признаки после одномерного фильтра (ОСФ), после отбора по частоте встречаемости в четырёх моделях (СПФ) и после рекурсивного отбора (РОП).
* **Средняя AUROC по этапам** — описательная величина: признаки отобраны по тем же данным, поэтому она растёт по построению.
* **Вложенная кросс-валидация** — несмещённая оценка точности: весь отбор повторяется только на обучающей части и проверяется на отложенных образцах.
* **База признаков** (`features_db`) пополняется при каждом прогоне: `runs_db.csv` — прогоны, `features_db.csv` — признаки с m/z, RT и отметками отбора, `intensities_db.csv` — интенсивности.

### Если что-то не так

* «Не найден файл…» — проверьте путь; пути можно указывать относительно папки проекта.
* «Слишком мало совпадений имён» — значения столбца `file` метаданных должны совпадать с первым столбцом таблицы (или с именами файлов без расширения).
* «Меньше двух признаков после ОСФ» — поправка Холма строгая; выберите поправку BH в параметрах.
