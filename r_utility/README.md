# UroMetabR 1.0.0 (2026-10-26)

**Программный инструмент для неинвазивной вспомогательной диагностики рака мочеполовой системы на основе анализа мочи методом ВЭЖХ-МС.**

Утилита на языке R (≥ 4.0.0) для полуавтоматической обработки данных ВЭЖХ-МС мочи: десять модулей (0–9) запускаются по очереди из одного главного скрипта или из графического интерфейса (Shiny), каждый сохраняет результат в свою подпапку проекта.

| № | Модуль | Файл |
|---|---|---|
| 0 | Загрузка и проверка входных данных (mzML/mzXML/CDF или CSV/TSV/TXT, метаданные) | `R/m0_input.R` |
| 1 | Оптимизация параметров (IPO) и таблица пиков (xcms) — только для сырых данных | `R/m1_peaktable.R` |
| 2 | Контроль качества: PCA с QC, пропуски, TIC, RSD | `R/m2_m4_quality.R` |
| 3 | Фильтр устойчивых признаков (RSD в QC ≤ 30 %, присутствие ≥ 50 % в группе) | `R/m2_m4_quality.R` |
| 4 | Удаление QC, усреднение повторов, сортировка по порядку ввода | `R/m2_m4_quality.R` |
| 5 | Заполнение пропусков (случайный лес, алгоритм missForest) | `R/m5_m6_impute_correct.R` |
| 6 | Коррекция сигнала (EigenMS) и логарифмирование | `R/m5_m6_impute_correct.R` |
| 7 | ОСФ → 4 модели (KNN, SVM, PLS, RF) → СПФ → РОП; вложенная кросс-валидация | `R/m7_select.R` |
| 8 | PCA и кластеризация по этапам, тепловая карта, диаграммы размаха, PLS-DA с VIP | `R/m8_visual.R` |
| 9 | База признаков (CSV с дозаписью) и отчёт HTML (R Markdown) | `R/m9_report.R` |

## Запуск
* **Windows:** `Start_UroMetabR.bat` (двойной щелчок). При первом запуске недостающие пакеты CRAN устанавливаются автоматически. Ярлык на рабочем столе создаёт `Create_desktop_shortcut.vbs`.
* **Linux/macOS:** `./start_urometabr.sh`.
* **Без интерфейса:** `Rscript run_analysis.R папка_проекта/settings.yaml [--from=N] [--to=M]`.

Порядок работы и формат метаданных — `docs/user_guide.md` (он же — вкладка «Справка» в интерфейсе).

## Проверка
```
Rscript tests/run_tests.R                                    # модульные тесты (алгоритмы и исправления этапа 1)
Rscript tests/ispytaniya.R --out=протокол [--setA=таблица,метаданные] [--setB=…] [--raw=папка_mzML,метаданные] [--cores=4]
```
`ispytaniya.R` выполняет 10 пунктов программы испытаний и собирает протокол (`protocol.csv`), журналы и `sessionInfo()` каждого прогона.

## Зависимости
CRAN: data.table, yaml, ggplot2, patchwork, pheatmap, caret, e1071, kernlab, randomForest, pls, foreach, doParallel, jsonlite, shiny, rmarkdown, knitr. Для сырых данных — Bioconductor: xcms, MSnbase (и IPO для оптимизации параметров).
